## 连接排障记录

最初 SSH 经系统 Geph 虚拟网卡超时。显式 `-F NUL -o ProxyCommand=none -o ProxyJump=none` 排除了 SSH 配置代理，但系统全局 VPN 仍影响路径。经管理员确认曾添加仅针对该 IP 的临时主机路由：`YOUR_SERVER_HOST/32` 经 WLAN 接口 6、网关 `192.168.0.1`；随后连接被本机套接字错误 10013 拒绝。用户在自己的 PowerShell 得到相同结果。

用户关闭全局 VPN 后直连登录成功，后续 SSH/SCP 均保持禁用代理。会话增加了 15 秒保活。临时主机路由未持久化，重启后失效；如需撤回，在管理员 PowerShell 使用：

```powershell
Remove-NetRoute -DestinationPrefix 'YOUR_SERVER_HOST/32' -InterfaceIndex 6 -NextHop '192.168.0.1' -PolicyStore ActiveStore -Confirm:$false
```

本机 HTTP 测试最初在受限执行环境的 asyncio socketpair 初始化处阻塞，在普通本机网络权限下全部通过。服务部署时 Docker internal 网络未实际发布 API 端口，已通过 API 单独增加 edge 桥接网络解决；数据库仍只使用私有网络。
