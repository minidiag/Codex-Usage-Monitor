# 工程隐私数据检查报告

检查日期：2026-10-26（北京时间）。对象：本地完整工程及本安装对应的当前 Windows 用户应用数据。仅检查，未删除文件、修改业务代码、解密凭据或改变采集状态。

## 结论

**完整工程目录包含个人数据和敏感运行资料，不适合原样公开或整目录分发。** 主要位于 `.local` 的旧版运行备份；源码及文档也保留真实基础设施地址和个人目录信息。

本轮规则扫描及命中复核**未发现明文真实密码、可识别的真实 OpenAI/遥测/GitHub 令牌、完整 JWT 或私钥**。密码字段的命中来自环境变量引用或合成测试。该结论是本次扫描结果，不是对所有可能编码、分片或未知密钥格式的绝对保证。

## 检查范围和方法

- 工程扫描快照：2,422 个文件，64,761,191 字节；包括隐藏目录、源码、文档、虚拟环境、二进制及缓存。
- 递归检查 56 个压缩容器（包含嵌套的第三方 wheel），覆盖 3 个服务端版本部署包及设计文档 ZIP。
- 只读检查 3 个 SQLite 数据库：工程内旧账本、当前用户账本、当前周期元数据队列。结合表结构核对本地存储的数据类型；未导出原始记录。
- 补查当前用户应用数据目录的 16 个可读文件，核对加密容器标记及部分敏感文件 ACL，未解密遥测凭据。
- 检查 4 张架构 PNG 的文本/EXIF 元数据，并目视核对其内容；未发现个人资料，图片内容均为方案图。
- 当前用户 `collector.lock` 由运行中的程序占用而不可读；它是进程锁文件，不为读取而停止采集器。
- 本工程当前没有 `.git`，不含可审计的 Git 历史。本次未连接远端服务器检查生产数据库、服务器 private/.env、远端日志或备份，也未扫描工程外的 Codex 原始登录与对话目录。

### 工程外当前用户运行资料

本安装将当前状态保存在 `%LOCALAPPDATA%/CodexUsageMonitor/<安装标识>/`：

- `client.credentials`：真实遥测凭据，DPAPI 加密。
- `state/local-profiles.json`、`state/avatars/`：明文账号显示名和本地头像路径；真实头像属于当前应用的本地资料，不能视为公开数据。
- `state/status.json`：账号显示资料、活动任务标题、会话信息及统计缓存。
- `state/collector.sqlite3`：数值检查点、日志路径、原始会话标识和匿名归属；扫描时有 273 条检查点，采集仍会继续增长。
- `state/quota-cycles.sqlite3`：匿名账号键、周期边界及待发送状态，扫描时有 4 条周期报告。

上述资料不在本工程根目录，但分享“故障排查资料”时容易误带。抽查的旧版与当前凭据、账本/状态及资料文件未发现向 Everyone、Users、Authenticated Users 广泛授权。DPAPI 标记检查通过；没有为验证而解密或打印凭据。管理员及系统账户仍按 Windows 权限模型具备相应访问能力。

## 隐私边界

姓名、头像、任务标题、日志路径和原始会话标识是本地展示/定位资料，当前上传白名单与其分离。服务器统计仍含稳定的账号/工作空间、Windows 用户、电脑匿名键，以及用量和事件时间；这些是可关联的假名化数据，不等同于不可关联的完全匿名数据，亦不适宜公开导出。

`.gitignore` 已忽略 `.local`、`.env`、private、backups、wheel 和 Python 缓存；`.dockerignore` 也排除 `.local`。忽略规则只影响对应工具，不会保护资源管理器直接压缩的整个文件夹，也不会清除已存在于压缩包或历史提交中的数据。

## 发布前处理顺序

1. 创建单独的发布副本，排除 `.local`、所有每用户状态、凭据、备份、虚拟环境及编译缓存，保留当前运行目录。
2. 将公开副本中的个人绝对路径、真实服务器地址和部署记录改为占位符；运行配置单独交付。
3. 检查最终发布压缩包的实际成员和内容，而不是仅检查源目录。
4. 若曾将真实明文凭据公开，撤销并重新签发；本轮没有发现此类明文泄露证据。

本轮只新增检查脚本和脱敏报告，未实施清理、替换地址、撤销凭据或修改部署包。
