# 本地头像账号界面（客户端 0.6.0）

2026-10-26。当前客户端 0.6.0，服务器 0.3.0、数据库版本 3。窗口标题为 Codex，头像和姓名居中，保留下拉切换；USAGE 括号累计与服务器周期持久化见 [额度周期统计](QUOTA-CYCLES.md)。下文头像资料隔离方式继续适用，历史验证数字保留其当时快照。

## 显示规则

- “Codex 用量”右侧显示 ChatGPT 桌面 App 对应账号的真实头像和明文名称，名称过长时省略，悬停可看完整名称。
- 点击头像/姓名区域展开账号列表，以明文名称和头像切换，周期数字、活跃会话分段与额度一起刷新。等待时清空旧数字，避免将旧账号数据显示为新账号。
- 默认选择主要 Codex 数据目录当前登录的账号；用户明确选择的账号或“全部账号”会保留。
- “全部账号”仅汇总当前 Windows 用户的账号；“未归属用量”仅包含已确认属于该 Windows 用户、账号尚不确定的增量。
- 本地窗口固定为当前 Windows 用户，移除 Windows 用户/电脑选择项。即使本机使用管理员查询凭据，窗口也不会查询租户总览或其他 Windows 用户。
- 匿名账号键、Windows 主体键和电脑键仅用于后台关联、上报和统计，不作为名称或提示文字显示。

服务器保留账号、Windows 用户和电脑的多维匿名统计，管理员仍可通过独立查询工具按权限查看。**本地窗口的范围不因管理员凭据扩大。**

## 名称与头像来源

名称优先取桌面 App 本机缓存中 `/backend-api/me` 的 `name`，读取前核对用户身份与 Codex 登录/本机会话创建者一致，避免使用另一个账号的缓存。没有可用桌面缓存时回退到本机登录身份声明的 `name`；不把邮箱或匿名键当作显示名。

头像优先取该个人资料引用的本机已缓存图片。如果本机没有图片，只允许对 OpenAI 官方头像来源发起普通 HTTPS 图片读取，不附带 bearer token 或 cookies，不发起登录，不跟随重定向。无法读取时显示姓名首字，不借用其他账号的头像。当前本机已经验证真实头像读取成功。

读取仅限本 Windows 用户的桌面缓存，不操作 ChatGPT 窗口、不提取浏览器 cookies 或密码、不复制整个个人资料响应。适配当前 Chromium blockfile 缓存布局，参考 [Chromium EntryStore](https://chromium.googlesource.com/chromium/src/net/+/HEAD/disk_cache/blockfile/disk_format.h) 和 [缓存地址格式](https://chromium.googlesource.com/chromium/src/+/b5035d51ba96304a61e151eed3e2eef67fc63086/net/disk_cache/blockfile/addr.h)。这是本地缓存适配器，桌面 App 更改格式时会保守回退，不影响数值采集。

缓存中 gzip/deflate 使用 Python 标准库解码；Brotli 可利用本机已安装的 Node.js 标准库，无第三方包和模型请求。未安装 Node.js 且只有 Brotli 缓存时，仍可显示登录资料中的明文名称；头像可能回退为首字。当前机器已有可用 Node.js。

资料刷新在独立线程中每约 60 秒进行，不阻塞五秒采集、上传或额度刷新。图片限制为支持的本地位图格式和大小；界面不直接加载网络图片 URI。头像更新后使用不同本地文件名，避免旧图片缓存。

## 明文资料仅留本机

每个 Windows 用户的应用数据目录中新增：

| 相对 state/ 的路径 | 内容 |
|---|---|
| `local-profiles.json` | 匿名键到明文名称及本机头像路径的映射 |
| `avatars/` | 供本机窗口显示的头像图片 |
| `status.json` 的 `local_profiles` | 本地展示白名单字段 |

这些文件与遥测数值账本、上传队列和上传接口分离。显示名、头像、头像路径、个人资料响应、邮箱、手机号和登录令牌均不进入统计上报。原头像 URL 不写入资料缓存，只保留用于更新判断的摘要。本地头像和名称不打入服务器部署包。

## 统计口径

四周期查询始终带当前 Windows 用户的匿名主体条件，再叠加账号条件；本机控制文件里的其他用户或电脑条件会被忽略。无法识别当前 Windows 主体时，不退回租户总量。旧版管理员范围缓存也不会被新窗口作为当前用户数据展示。

活跃会话同样只累计本地账本中**已确认归属当前 Windows 用户**的检查点增量，按所选账号过滤。它是会话内已采集分段累计，不是 `threads.tokens_used` 的跨用户整段历史，也不额外加到周期总量。

升级前未归属到 Windows 用户的历史仍保留在服务器，不能据当前登录状态自动认领。因此本窗口数字可能小于原管理员总览；这表示范围收窄，不是删除或重置账本。
